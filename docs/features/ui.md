# 화면 구성

```
┌────────────────────────────────────────────────────────────┐
│ TopBar                      [환경 선택] [변수] [쿠키] [설정] │
├──────────────┬─────────────────────────────────────────────┤
│ Sidebar      │ TabBar   [요청 A] [요청 B ●] [Runner] ...     │
│  Collections │ ┌─────────────────────────────────────────┐ │
│  History     │ │ [GET ▾] [URL                ] [Send]   │ │
│              │ │ Params Headers Body Auth Cookies ...   │ │
│  트리        │ ├─────────────────────────────────────────┤ │
│              │ │ 응답: 200 OK · 120 ms · 1.2 KB          │ │
│              │ │ Body Headers Cookies Request Tests     │ │
│              │ └─────────────────────────────────────────┘ │
├──────────────┴─────────────────────────────────────────────┤
│ Console (열었을 때만, 높이 조절 가능)                       │
├────────────────────────────────────────────────────────────┤
│ StatusBar                                                  │
└────────────────────────────────────────────────────────────┘
```

- 사이드바와 본문 사이, 요청 편집기와 응답 사이의 경계를 드래그해 크기를 바꿀 수 있고, 크기는 기억된다.
- 다크/라이트 테마는 OS 설정을 따른다.

## 사이드바

- **Collections** — 열린 컬렉션들의 트리. 상단 버튼으로 새 요청, cURL 가져오기, 새 컬렉션 만들기, 컬렉션 폴더 열기를 한다. 트리 위의 검색 입력란으로 요청·변수를 찾는다. 자세한 조작은 [컬렉션과 폴더](collections.md), [검색](search.md).
- **History** — 최근 보낸 요청. [히스토리](history.md).

## 탭

- 요청, WebSocket, 폴더 설정, 컬렉션 설정, 러너가 각각 탭으로 열린다.
- 저장하지 않은 변경이 있으면 탭에 `●`가 표시되고, 닫을 때 저장 여부를 묻는다. 저장하면 그 자리에 체크가 잠깐 보였다가 사라진다.
- 요청을 보내는 중인 탭은 메서드 표시 자리에 스피너가 돈다. 다른 탭을 보고 있어도 어느 요청이 진행 중인지 알 수 있다.
- 가운데 클릭으로 닫기, 우클릭 메뉴로 Close / Close Others 등을 쓸 수 있다.
- 열린 탭 목록은 재시작 시 복원되지 않는다. 컬렉션 목록만 복원된다.
- `Ctrl+Shift+T`(macOS `⌘⇧T`)로 최근 닫은 탭을 역순으로 복원한다(최대 20개, 앱 실행 중에만 보관). 닫기 전 초안과 저장 상태를 원래 탭 위치에 복원하며, 요청 재전송이나 WebSocket 재연결은 하지 않는다. 응답·연결 상태는 복원하지 않는다. 이미 같은 파일이 열려 있으면 그 탭으로 이동한다. 파일 삭제·컬렉션 닫기로 제거된 항목은 복원 대상에서 제외한다.

## 단축키

macOS는 ⌘, Windows는 Ctrl.

| 키 | 동작 |
| --- | --- |
| ⌘S | 현재 탭 저장 (저장 위치가 없으면 Save As) |
| ⌘N | 새 요청 탭 |
| ⌘D (사이드바 항목 포커스) | 요청·WebSocket·폴더 복제 |
| F2 (사이드바 항목 포커스) | 이름 변경 |
| F5 / ⌘R | 열린 컬렉션의 파일 목록 다시 읽기 |
| ⌘K | 사이드바 검색 입력란으로 이동 (History 탭이면 Collections로 전환) |
| ⌘W | 현재 탭 닫기 |
| ⌘L | HTTP·WebSocket의 URL 입력란으로 이동하고 주소 전체 선택 |
| ⌘⇧T | 최근 닫은 탭 복원 |
| ⌘/ | 단축키 도움말 열기 |
| Enter (URL 입력란) | 요청 전송 |
| Tab / Shift+Tab (단일행 입력란) | 다음 / 이전 입력란이나 컨트롤로 포커스 이동 |
| ⌘Enter | 요청 전송 (포커스 위치와 관계없이, 보내는 중이면 무시) |
| ⌘1–8 / ⌘9 | n번째 탭 / 마지막 탭으로 이동 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 (양쪽 OS 모두 Ctrl) |
| ⌘⇧] / ⌘⇧[ | 다음 / 이전 탭 (macOS만) |
| ⌘, | 설정 열기 |
| ⌘⇧B | 응답 Body 보기 방식 전환 (Pretty → Raw → Preview) |

모달이 열려 있을 때는 ⌘Enter, 탭 이동, ⌘,, ⌘⇧B가 동작하지 않는다. 편집기 안에서 ⌘Enter는 빈 줄을 넣지 않고 요청을 보낸다.

⌘L·⌘⇧T·⌘/는 코드 편집기 안에서도 동작하며, 모달이 열려 있거나 한글 등 IME 조합 중이면 실행하지 않는다. URL 입력란이 없는 탭에서는 ⌘L로 이동하지 않는다. 단축키 도움말은 Esc 또는 Close 버튼으로 닫는다.

사이드바 항목을 클릭하거나 Tab으로 포커스를 옮긴 뒤 복제·이름 변경 단축키를 쓴다. 텍스트 편집 중이거나 모달이 열려 있으면 실행하지 않는다. 새로고침 키는 웹뷰를 재로딩하지 않으며, Shift를 함께 누르는 강제 새로고침 조합도 컬렉션 목록 갱신으로 처리한다. 열린 요청의 편집 내용·응답·탭은 유지한다. 모달이 열려 있으면 목록 갱신도 실행하지 않는다.

Params·Headers·폼 데이터·경로 변수와 변수·리스트 항목 등 키-값 테이블의 단일행 입력란에서는 Tab으로 들여쓰기를 넣지 않고 포커스를 이동한다. URL·인증 등 같은 단일행 편집기를 쓰는 입력란에도 적용된다. 여러 줄을 편집하는 Body·스크립트에서는 Tab 들여쓰기를 유지한다.

## 콘솔

하단 독으로 열리며, 위쪽 경계를 드래그해 높이를 바꾼다(높이는 저장된다). 요청마다 메서드·URL·상태 코드·소요 시간이 한 줄로 남고, 그 아래에 스크립트의 `console` 출력과 오류가 표시된다. 오류에는 어느 단계(컬렉션/폴더/요청, Pre/Post)에서 났는지가 함께 적히고, `console` 출력은 마우스를 올리면 단계가 보인다. 최근 200개 요청까지 보관하며, 오류(스크립트 오류, 전송 실패)가 나면 콘솔이 자동으로 열린다.

요청 줄을 누르면 펼쳐져 상세가 보인다.

- **Request** — 실제로 전송한 메서드·URL·헤더·바디. 변수와 인증이 치환된 값이라 비밀 변수의 값도 그대로 보인다.
- **Response** — 상태 코드, 헤더, 바디.
- 바디는 각각 64 KB까지만 보여주고, 넘으면 잘렸다는 안내가 붙는다. 바이너리 응답은 `<binary N bytes>`로 표시한다.
- 전송에 실패한 요청은 응답 대신 오류 내용이 보인다.

## 피드백과 알림

- 모션은 짧게(100–150ms) 쓰고, 모달·메뉴·콘솔은 열릴 때만 움직이고 닫을 때는 바로 사라진다. OS의 "동작 줄이기" 설정과 관계없이 같다.
- 버튼은 누르는 순간 살짝 줄어들고, 트리·탭·메뉴 항목은 배경이 어두워진다.
- 트리 폴더는 펼치고 접을 때 높이가 부드럽게 바뀐다. 탭은 열릴 때 펼쳐지고 닫힐 때 줄어들며 사라진다.
- **토스트**는 우측 하단에 최대 3개까지 쌓인다. 성공은 2초, 실패는 5초 뒤 사라지고, 클릭하면 바로 닫힌다. 토스트로 알리는 일:
  - 누른 버튼이 사라지는 복사 (트리 메뉴의 Copy Path)
  - Import 완료(가져온 요청 수), Export 완료(저장 경로)
  - OAuth 토큰 받기 성공·실패
  - 파일 작업 실패 (컬렉션 열기, 생성, 저장, 이름 변경, 복제, 삭제, 이동, 가져오기, 내보내기, 응답 본문 저장)
- 화면 안에서 끝나는 동작은 그 자리에서 알린다. 복사 버튼은 체크로 바뀌었다가 돌아오고, ⌘S로 저장하면 탭의 `●`가 잠깐 체크로 바뀐다.
- 오래 걸리는 작업에는 스피너를 붙인다: 요청 전송, 러너, Import, OAuth 토큰 받기, WebSocket 연결.
