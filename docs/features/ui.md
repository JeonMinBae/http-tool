# 화면 구성

```
┌────────────────────────────────────────────────────────────┐
│ TopBar        [검색 ⌘K]      [환경 선택] [변수] [쿠키] [설정] │
├──────────────┬─────────────────────────────────────────────┤
│ Sidebar      │ TabBar   [요청 A] [요청 B ●] [Runner] ...     │
│  Collections │ ┌─────────────────────────────────────────┐ │
│  History     │ │ [GET ▾] [URL                ] [Send]   │ │
│              │ │ Params Headers Body Auth Cookies ...   │ │
│  트리        │ ├─────────────────────────────────────────┤ │
│              │ │ 응답: 200 OK · 120 ms · 1.2 KB          │ │
│              │ │ Body Headers Cookies Request Tests     │ │
│              │ └─────────────────────────────────────────┘ │
├──────────────┴─────────────────────────────────────────────┤
│ Console (열었을 때만, 높이 조절 가능)                       │
├────────────────────────────────────────────────────────────┤
│ StatusBar                                                  │
└────────────────────────────────────────────────────────────┘
```

- 사이드바와 본문 사이, 요청 편집기와 응답 사이의 경계를 드래그해 크기를 바꿀 수 있고, 크기는 기억된다.
- 다크/라이트 테마는 OS 설정을 따른다.

## 사이드바

- **Collections** — 열린 컬렉션들의 트리. 상단 버튼으로 새 요청, cURL 가져오기, 컬렉션 폴더 열기를 한다. 자세한 조작은 [컬렉션과 폴더](collections.md).
- **History** — 최근 보낸 요청. [히스토리](history.md).

## 탭

- 요청, WebSocket, 폴더 설정, 컬렉션 설정, 러너가 각각 탭으로 열린다.
- 저장하지 않은 변경이 있으면 탭에 `●`가 표시되고, 닫을 때 저장 여부를 묻는다.
- 가운데 클릭으로 닫기, 우클릭 메뉴로 Close / Close Others 등을 쓸 수 있다.
- 열린 탭 목록은 재시작 시 복원되지 않는다. 컬렉션 목록만 복원된다.

## 단축키

macOS는 ⌘, Windows는 Ctrl.

| 키 | 동작 |
| --- | --- |
| ⌘S | 현재 탭 저장 (저장 위치가 없으면 Save As) |
| ⌘N | 새 요청 탭 |
| ⌘K | 빠른 검색 |
| ⌘W | 현재 탭 닫기 |
| Enter (URL 입력란) | 요청 전송 |

## 콘솔

하단 독으로 열리며, 위쪽 경계를 드래그해 높이를 바꾼다(높이는 저장된다). 요청마다 메서드·URL·상태 코드·소요 시간이 한 줄로 남고, 그 아래에 스크립트의 `console` 출력과 오류가 표시된다. 오류에는 어느 단계(컬렉션/폴더/요청, Pre/Post)에서 났는지가 함께 적히고, `console` 출력은 마우스를 올리면 단계가 보인다. 최근 200개 요청까지 보관하며, 오류(스크립트 오류, 전송 실패)가 나면 콘솔이 자동으로 열린다.
