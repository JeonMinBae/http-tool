# 컬렉션 러너

컬렉션이나 폴더 안의 요청을 차례로 실행한다. 컬렉션·폴더 우클릭 → Run Collection / Run Folder로 Runner 탭을 연다.

## 설정

| 항목 | 설명 |
| --- | --- |
| 요청 목록 | 하위 폴더까지 포함한 HTTP 요청 목록. 체크로 포함 여부를 고르고, 드래그로 순서를 바꾼다 |
| Iterations | 전체 목록을 몇 번 반복할지 (1 이상) |
| Delay (ms) | 요청 사이 대기 시간 |
| Stop on failure | 실패가 나면 즉시 멈춤 |

WebSocket 요청은 목록에 나오지 않는다.

## 실행

- 각 요청은 **저장된 파일 내용**으로, 일반 전송과 똑같이 실행된다. 탭에서 고치고 저장하지 않은 내용은 반영되지 않는다. 스크립트, 인증 상속, 변수, 쿠키, 히스토리 기록이 모두 적용된다.
- 앞 요청의 스크립트가 저장한 환경·컬렉션 변수를 다음 요청이 쓸 수 있다 (예: 로그인 → 토큰 저장 → 이후 요청).
- **실패 기준**: 연결 오류, 스크립트 오류, 또는 실패한 `pm.test`가 하나라도 있으면 실패다. HTTP 4xx/5xx 자체는 실패로 보지 않는다. 상태 코드를 검사하려면 테스트를 쓴다.
- Stop 버튼으로 언제든 멈출 수 있다.
- 실행 중에는 `Running… 완료 수 / 전체 수`와 진행 바가 보이고, 결과 표 맨 아래에 지금 실행 중인 요청이 스피너와 함께 표시된다. 요청 사이 Delay 동안에는 다음 요청이 표시된다.

## 결과

- 요청별 행: 번호, 요청 이름, 상태 코드(실패 시 Error), 소요 시간, 테스트 (통과/전체)
- 행을 누르면 요청 줄, 테스트 결과, 오류, 응답 본문 앞부분(20KB)을 볼 수 있다.
- 요약: 전체 요청 수, 실패 수, 테스트 통과·실패 수, 총 소요 시간, 중단 여부

SSE 응답은 러너에서 스트리밍하지 않는다. 스트림이 끝나거나 타임아웃이 날 때까지 기다린다.
