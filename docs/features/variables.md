# 변수와 환경

URL, 헤더, 파라미터, 바디, 인증 값 등 거의 모든 입력에 `{{이름}}` 형식으로 변수를 쓸 수 있다.

## 스코프와 우선순위

같은 이름이 여러 곳에 있으면 위쪽이 이긴다.

| 순위 | 스코프 | 저장 위치 | 설정 방법 |
| --- | --- | --- | --- |
| 1 | 지역 (local) | 저장하지 않음 (요청 1회 실행 동안만) | 스크립트의 `pm.variables.set()` |
| 2 | 환경 (environment) | 앱 데이터 | TopBar의 환경 선택 → 변수 대화상자 |
| 3 | 컬렉션 (collection) | `collection.yaml` | Collection Settings → Variables |
| 4 | 전역 (global) | 앱 데이터 | 변수 대화상자의 Globals |

- 꺼진 변수와 이름이 빈 변수는 없는 것으로 본다.
- 변수 값 안의 `{{다른 변수}}`도 치환한다 (최대 5단계).
- 해석되지 않은 변수는 `{{이름}}` 그대로 전송되고, 응답 위에 경고가 표시된다.
- 일반 변수 이름에는 `:`를 쓸 수 없다. `:`가 든 이름은 해석에서 빠지고 변수 표에 오류가 표시된다 (자동으로 고치지 않는다). `:`는 아래 목록형 변수 참조에만 쓴다.

## 환경

- 환경은 앱 전체에서 공유된다. 컬렉션과 무관하게 "dev", "staging", "prod" 같은 묶음을 만들어 두고 TopBar에서 고른다.
- 선택한 환경은 재시작 후에도 유지된다.
- 환경을 고르지 않으면 환경 스코프는 비어 있다. 이때 스크립트의 `pm.environment.set()`은 무시된다.

## 목록형 변수

변수 표의 Type을 `List`로 바꾸면 이름 하나에 `항목 키 → 값` 쌍 여러 개를 담는다. 환경, 컬렉션, 전역 변수 어디서나 쓸 수 있다.

- 참조는 `{{목록:항목}}`이다. 예: 목록 `tool`에 `A`, `B` 항목이 있으면 `{{tool:A}}`. 항목 키에 `:`가 있으면 첫 `:`에서 나눈다 (`{{tool:A:B}}`는 목록 `tool`의 항목 `A:B`).
- **통째 덮어쓰기**: 같은 이름의 목록이 여러 스코프에 있으면 우선순위가 가장 높은 스코프의 목록 하나만 쓴다. 그 목록에 없는 항목을 낮은 스코프의 목록에서 가져오지 않는다.
- 항목이 없거나 `{{tool:}}`처럼 항목 키가 비어 있으면 해석되지 않은 변수로 보고 경고한다. 목록 이름만 쓴 `{{tool}}`은 목록이 아니라 같은 이름의 일반 변수를 찾는다.
- 같은 이름의 일반 변수와 목록은 따로 취급한다. 꺼진 목록·꺼진 항목·키가 빈 항목은 없는 것으로 본다.
- 변수 표: 목록 행의 값 칸에는 `▸ n items`가 나오고, 눌러 펼치면 항목 표(Item · Value)가 열린다. Type · Secret 칸에서 Text와 List를 바꾸며, 바꾸면 이전 형태의 값은 지워진다. 목록이 하나라도 있으면 Bulk Edit 버튼은 숨겨진다.
- 스크립트에서는 `pm.environment.get("tool:A")`처럼 읽고 쓴다. [스크립트](scripts.md)

## 비밀 변수

변수 표의 Secret 체크를 켜면 다음처럼 동작한다.

- 화면에서 값이 가려진다 (Show secrets로 잠깐 볼 수 있음).
- 컬렉션 변수인 경우 `collection.yaml`에는 빈 값으로 저장되고, 실제 값은 이 PC의 앱 데이터에만 저장된다. 컬렉션 폴더를 git으로 공유해도 값이 나가지 않는다.
- 검색 결과에도 값이 표시되지 않는다.
- 목록형 변수에 켜면 모든 항목 값에 적용된다. 항목 값은 `collection.yaml`과 내보내기에서 빈 값이 되고, 이 PC의 앱 데이터에는 `목록:항목` 키로 저장된다. [저장 구조](../storage.md#비밀-변수)

## 스크립트에서 바꾼 변수

스크립트가 `pm.environment.set()`, `pm.collectionVariables.set()`, `pm.globals.set()`으로 바꾼 값은 요청이 끝난 뒤 해당 스코프에 저장된다. 지역 변수는 실행이 끝나면 사라진다. [스크립트](scripts.md)

## 편집기 지원

URL 입력란, raw·GraphQL 바디, WebSocket URL·메시지 편집기에서:

- 변수 이름은 색으로 표시된다. 해석되지 않는 이름은 경고 색이다.
- 마우스를 올리면 현재 값과 어느 스코프에서 왔는지 보인다.

키-값 표(Params, Headers, Cookies, form-data, x-www-form-urlencoded, 경로 파라미터 값, 폴더·컬렉션 설정의 표)와 인증 입력란(OAuth 2.0 포함), WebSocket Headers 표도 같은 강조 표시와 자동완성을 쓴다. 변수 표의 값 칸은 일반 입력란이라 강조와 자동완성이 없다. 변수 치환은 똑같이 된다.

### 자동완성

- `{{`를 입력하거나 Ctrl+Space(수동 호출)를 누르면 변수 후보가 나온다. 입력한 글자로 후보가 걸러진다.
- 후보에는 이름, 스코프, 현재 값이 보인다. 같은 이름은 [우선순위](#스코프와-우선순위)가 높은 스코프 하나만, 선택한 환경 기준으로 나온다. 목록형 변수는 항목마다 `목록:항목`으로 나온다.
- 목록 이름 뒤에 `:`를 입력하면(`{{tool:`) 그 목록의 항목 키만 보인다.
- 비밀 변수의 값은 `••••••`로 가려진다.
- 고르면 `이름}}`을 넣는다. 커서 뒤에 이미 `}}`가 있으면 중복해서 넣지 않는다. Ctrl+Space로 부른 경우에는 `{{이름}}` 전체를 넣는다.
- 적용 범위: URL, raw·GraphQL 바디, WebSocket URL·메시지 편집기, 위의 키-값 표와 인증 입력란.
