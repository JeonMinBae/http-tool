# 응답 보기

요청을 보내는 동안에는 스피너와 경과 시간(0.1초 단위)이 표시된다.

응답 영역 상단에는 상태 코드, HTTP 버전, 소요 시간, 크기가 표시된다. 응답이 도착하면 이 줄이 상태 색(2xx 초록, 3xx 파랑, 4xx 노랑, 5xx 빨강)으로 한 번 빛난다. 같은 응답이 반복돼도 매번 빛나고, 탭을 오갈 때나 히스토리에서 지난 응답을 열 때는 빛나지 않는다. 리다이렉트를 따라갔으면 그 아래에 각 단계(상태 코드, 메서드, 경로)가 이어서 표시되고, 마우스를 올리면 전체 URL이 보인다. 오류(연결 실패, 타임아웃 등)가 나면 오류 메시지가 대신 표시되고 빨강으로 한 번 빛난다.

## 탭

| 탭 | 내용 |
| --- | --- |
| Body | 응답 본문. SSE 응답이면 Events 탭으로 바뀐다 ([SSE와 WebSocket](streaming.md)) |
| Headers | 응답 헤더 |
| Cookies | 응답의 `Set-Cookie`를 표로 정리 |
| Request | 실제로 보낸 요청 (아래 참고) |
| Tests | `pm.test` 결과. 실패 개수나 스크립트 오류 표시가 탭에 뜬다 |

## Body 보기 방식

- **Pretty** — JSON·XML·HTML을 들여쓰기해 문법 강조와 함께 보여준다. 5MB가 넘으면 Pretty를 쓸 수 없다.
- **Raw** — 받은 그대로.
- **Preview** — HTML을 미리보기로 렌더링한다. 스크립트가 실행되지 않는 sandbox iframe을 쓴다. 이미지 응답은 이미지로 보여준다.
- 그 밖의 바이너리 응답은 내용 대신 유형을 표시한다.
- **Save to file**로 본문 전체를 파일에 저장할 수 있다. 저장에 실패하면 토스트로 알린다.

## Request 탭 (보낸 요청)

변수 치환, 인증, 기본 헤더, 쿠키 저장소가 모두 적용된 뒤 **실제로 전송된** 요청을 보여준다.

- 요청 줄, 헤더, 바디 (바디는 앞부분 1MB까지)
- 리다이렉트를 따라갔으면 마지막 단계의 요청. 중간 단계는 응답 상단에 표시된다
- `User-Agent` 등 자동으로 붙은 헤더와 쿠키 저장소에서 붙은 `Cookie`도 포함된다

스크립트가 요청을 바꿨거나 상속된 인증이 붙었을 때, 무엇이 나갔는지 이 탭에서 확인한다.
