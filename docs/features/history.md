# 히스토리

보낸 요청은 저장 여부와 관계없이 자동으로 기록된다.

- 사이드바의 History에서 날짜별(오늘, 어제, 날짜)로 묶어 최신순으로 보여준다. 각 줄에는 메서드, 호스트와 경로, 상태 코드가 나오고, 마우스를 올리면 전체 URL, 시각, 오류가 보인다.
- 항목을 누르면 그때의 요청 정의(스크립트 실행 전)와 응답이 새 탭으로 열린다. 이 탭은 저장되지 않은 요청이라, ⌘S로 컬렉션에 저장할 수 있다.
- Clear all로 확인 후 전체 기록을 지운다.

## 보관 규칙

- 기본 500건까지 보관하고, 넘으면 오래된 것부터 지운다. 개수는 [네트워크 설정](settings.md)에서 1~10000 사이로 바꾼다.
- 응답 본문은 1MB까지만 저장한다. 잘렸다는 표시는 저장되지만 화면에는 아직 나오지 않는다.
- 요청을 실제로 보낸 경우만 기록된다. 연결 실패·타임아웃처럼 응답이 없는 요청은 오류 메시지와 함께 기록된다.
- 보내기 전에 실패한 요청(Pre 스크립트 오류, OAuth 토큰 실패, 빈 URL 등)은 기록되지 않는다.
- 앱 데이터의 `history/` 폴더에 저장된다.
