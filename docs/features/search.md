# 검색

⌘K(Windows는 Ctrl+K) 또는 TopBar 가운데의 검색 버튼으로 빠른 검색 창을 연다.

## 검색 대상

- **요청** — 열린 모든 컬렉션의 HTTP 요청 이름, URL, 경로. 결과에 메서드와 폴더 경로가 함께 보인다. WebSocket은 검색되지 않는다.
- **변수** — 전역, 환경, 컬렉션 변수의 이름과 값. 어느 스코프에 있는지 함께 보인다. 비밀 변수의 값은 검색·표시하지 않는다.

## 사용

- 검색어를 공백으로 나눠, 모든 단어가 포함된 항목만 나온다 (대소문자 무시).
- 순서: 이름이 검색어로 시작 > 이름에 포함 > URL·경로·값에 포함. 결과는 최대 50개.
- 위/아래 화살표로 고르고 Enter로 연다.
  - 요청: 탭으로 연다 (이미 열려 있으면 그 탭으로 이동).
  - 변수: 그 변수가 있는 곳(변수 대화상자 또는 Collection Settings)을 연다.
- Esc로 닫는다.
