# 검색

사이드바 Collections 탭 위쪽의 검색 입력란에서 요청과 변수를 찾는다. ⌘K(Windows는 Ctrl+K)를 누르면 이 입력란으로 포커스가 옮겨 간다. History 탭을 보고 있었으면 Collections로 전환된다.

입력란 아래의 **[Requests | Variables]** 토글로 검색 대상을 고른다. 기본은 Requests이고, 선택과 검색어는 재시작 시 복원되지 않는다. Esc를 누르면 검색어를 지운다.

## Requests

검색어로 컬렉션 트리를 걸러 보여준다. 대소문자를 구분하지 않는 부분 문자열 일치다.

- **컬렉션·폴더**는 이름으로, **요청**(HTTP·WebSocket)은 이름 또는 URL로 일치를 본다.
- 일치한 컬렉션·폴더는 하위 전체를 그대로 보여준다. 일치한 항목의 상위 폴더도 함께 보인다.
- 일치한 항목의 상위 컬렉션·폴더는 자동으로 펼쳐진다. 펼침 상태는 필터 중에만 따로 바뀌므로, 검색어를 지우면 이전 펼침 상태로 돌아간다.
- 필터 중에는 드래그앤드롭이 꺼진다.
- 일치하는 것이 없으면 "No matches."가 보인다.

## Variables

컬렉션·전역·환경 변수를 이름·값·스코프와 함께 목록으로 보여준다.

- 검색어를 공백으로 나눠 모든 단어가 이름 또는 값에 포함된 변수만 나온다. 이름이 검색어로 시작 > 이름에 포함 > 값에 포함 순으로 정렬하고, 결과는 최대 50개다.
- 비밀 변수의 값은 `••••••`로 가려지고, 값으로는 검색되지 않는다.
- 결과를 누르면 그 변수가 있는 곳을 연다. 전역·환경 변수는 변수 대화상자, 컬렉션 변수는 Collection Settings 탭이다.
